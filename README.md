**Premium On-Demand Driver Booking for Your Personal Vehicle**

DriveMate is a modern, premium web application that allows users to book professional drivers to drive their own cars. Designed with a focus on minimalism, safety, and reliability, the platform delivers an experience akin to top-tier ride-hailing apps, tailored specifically for personal vehicle owners.

## 📱 App Concept
DriveMate bridges the gap between car owners and professional drivers. Whether you need a driver for a daily commute, an outstation trip, a round-trip, or a designated driver after an event, DriveMate provides verified professionals on demand. 

The UI/UX is heavily inspired by Apple’s Human Interface Guidelines, featuring a clean glassmorphism aesthetic, smooth micro-interactions, native-feeling transitions, and full Light/Dark mode support.

## ✨ Core Features

### For Customers
* **Multi-Mode Booking:** One-way, round-trip, hourly packages, outstation, and designated driver modes.
* **Live Tracking & Map Integration:** Real-time driver location and ETA calculation.
* **Flexible Payments:** UPI, Credit/Debit Cards, Apple Pay, Wallets, and Cash.
* **Safety First:** Emergency SOS button, live ride-sharing with family, and verified driver profiles.
* **History & Receipts:** Comprehensive booking history, favorite locations, and downloadable PDF trip receipts.

### For Drivers
* **Seamless Onboarding:** Document uploads (License, ID, Selfie) and background verification.
* **Flexible Scheduling:** Online/offline toggle and availability scheduling.
* **Driver Dashboard:** Earnings overview, wallet payouts, trip history, and navigation guidance.
* **Interactive Requests:** Accept/reject ride requests with clear routing and pricing details.

### For Administrators
* **User Management:** Full oversight of customer and driver profiles.
* **Verification System:** Approve or reject driver verification documents.
* **Live Monitoring:** Real-time trip tracking and booking management.
* **Financials & Analytics:** Dynamic pricing controls, promo code management, and revenue reports.

## 🛠️ Tech Stack
This project is built using a modern, fast, and scalable frontend stack:
* **Framework:** React 19
* **Routing:** TanStack Router (with Server-Side Rendering support)
* **Styling:** Tailwind CSS v4 (Component-based architecture)
* **Build Tool:** Vite
